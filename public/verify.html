How this works: each stage-history entry is canonicalized as id|parcelId|stage|enteredOn|exitedOn|handledByRole|note, then hashed as SHA-256(previousHash + "|" + canonical), starting from a genesis hash of 64 zeroes. This is the exact same algorithm BhoomiSetu itself uses to seal the chain (src/domain/auditChain.ts) — this page reimplements it independently in plain JavaScript using the browser's built-in crypto.subtle, so a match here is not just "the app says it's fine", it is an independent recomputation reaching the same answer.
